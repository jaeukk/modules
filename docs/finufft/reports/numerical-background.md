## Source-derived numerical mapping

The following is a derivation from the application's inspected code and the pinned manual; it is not a transcription attributed to either paper.

Let the columns of **B** be the direct cell basis vectors, **rⱼ = B sⱼ** be Cartesian positions, Ω = |det B|, and integer mode **m** correspond to physical reciprocal vector **kₘ = 2π B⁻ᵀm**. `core/PeriodicCellList.h:938` constructs reciprocal vectors with this 2π convention. Recover a stored physical mode using mₗ = bₗ·k/(2π), round only after verifying integrality with a scale-aware tolerance, and reject/fall back for truly non-lattice constraints. Public `AddConstraint` accepts arbitrary physical vectors, so the type 1 path cannot silently assume all callers supply lattice modes.

Use **θⱼ = 2π(sⱼ − floor(sⱼ + 1/2))**, componentwise, in [−π, π). This wraps by whole periods and preserves phase; mapping `2πs−π` instead introduces a mode-dependent phase unless compensated. For orthogonal boxes this reduces to 2πrₗ/Lₗ wrapped; skew cells require the basis transformation. Wrapped angles also satisfy the pinned manual's conservative coordinate-range description.

For species s, `potential/CollectiveCoordinatePotential.h:82` computes

    ρₛ(m) = Σⱼ∈s exp(+i kₘ·rⱼ) = Σⱼ∈s exp(+i m·θⱼ).

Thus use type 1, **isign=+1**, strengths cⱼ=1, **no division by particle count, mode count, or cell volume** in the transform. `HAVETWOFIXEDPARTICLES`, if enabled, adds real 2 to every density; this macro needs an explicit compatibility test or fallback. `ShiftedCCPotential_withWeight` instead uses its supplied particle weights and is a separate compatibility case.

The exact base energy at `CollectiveCoordinatePotential.h:142` is

    Eₛ = Ω⁻¹ Σₘ∈Hₛ Vₛₘ |ρₛ(m)|² + Shiftₛ.

`MultiStealthyPotential.cpp:Energy` combines it as

    E = u₀ Σₛ (Nₛ/N) Eₛ + e₀ Econtact.

Keep every actual stored V, shift, species population factor, and u₀/e₀ multiplier. Structure-factor reporting S=|ρ|²/Nₛ is a diagnostic convention and must not introduce an extra 1/Nₛ into the implemented energy. The contact term uses radii as actual soft-overlap diameters, not merely visual decoration, when enabled.

### Ordering, pairs, and cutoffs

`core/PeriodicCellList.cpp:509` selects reciprocal vectors with **first nonzero integer component positive**, excludes zero, and excludes |k|²≤Kmin². The default neighbor path uses a strict radial comparison in `PeriodicCellList.h:836`; the explicit enumeration branch also uses |k|²<Kmax². `main.cpp:1227` then applies its lower cutoff with another strict `>` test. Preserve the existing returned constraint list; do not regenerate a geometrically similar set from a floating cutoff. The single-component target-count path (`main.cpp:663–703`) adjusts shells and reports its actual list size.

H is already one representative per ± pair. Do **not** double the energy or assume a missing 1/2. For real strengths ρ(−m)=conj ρ(m), but the simplest gradient implementation populates only H in an otherwise zero coefficient grid. A symmetric ± extension is possible only with weights halved appropriately and a demonstrated equivalent force. Duplicate stored constraints must remain additive; accumulating their coefficients is necessary.

For `modeord=0`, choose odd sizes nₗ=2 max|mₗ|+1, including nₗ=1 for an unused direction, and index mₗ at mₗ+floor(nₗ/2). Odd sizes include both extreme signs and avoid accidentally identifying +n/2 with the negative endpoint of an even grid. C/C++ uses the **first dimension fastest**, so in 2D flat index = i₀+n₀i₁; in 3D add n₀n₁i₂. Python array indexing follows its documented wrapper layout, as used by the separate probe. `modeord=1` would use wrapped FFT indices; set the choice explicitly rather than depend on defaults. A zero-constraint case should return shift/zero CC force without creating a plan; particle-empty species also needs explicit handling.

The code reports realized χₛ=Mₛ/[d(Nₛ−1)] for Nₛ≥2. Its multi-species `chi` input is converted to a cutoff using the **total** density, not species density (`main.cpp:1187`). Equal requested values therefore need not mean the intended per-species χ. The backend should preserve this definition; experimental setup must separately construct/count the intended per-species modes.

### Forward, adjoint, gradient, and force

Define Aₘⱼ=exp(+ikₘ·rⱼ) so ρ=A1. Its Hermitian adjoint uses the opposite sign: (A* f)ⱼ=Σₘ fₘ exp(−ikₘ·rⱼ). For Cartesian component a form

    Dₘₐ = Vₘ kₘₐ ρ(m),          zⱼₐ = Σₘ∈H Dₘₐ exp(−ikₘ·rⱼ).
    ∂Eₛ/∂rⱼₐ = (2/Ω) Im zⱼₐ,  Fⱼₐ = −(2/Ω) Im zⱼₐ.

Use type 2 **isign=−1**, zero-filled unconstrained modes, and one coefficient set per dimension (batched if useful). This agrees with the direct force's `−2 V (ρimag cos − ρreal sin) k / Ω` at `CollectiveCoordinatePotential.h:168`. Apply u₀Nₛ/N outside the species calculation exactly as the wrapper currently does. Real particle strengths aⱼ require an additional factor aⱼ in the position derivative; complex strengths require the general complex chain rule and should not be silently treated as real.

`potential/StructureOptimization.cpp:471–494` requests **AllForce** and converts to optimizer relative-coordinate gradients as −F·bₗ/RelativeCoordinatesRescale. Return Cartesian force through that interface; converting twice would be wrong. Basis-vector/cell derivatives are not supplied by the simple position-gradient derivation and should remain out of scope or direct-only until separately derived.

### Adjoint is not inverse reconstruction

The reciprocal-to-particle calculation above is A*, a Fourier-series evaluation at already-known particle positions. Generally A*A is not identity. Reconstructing strengths at fixed locations is a linear inverse problem, for example minimizing ‖W¹ᐟ²(Ac−y)‖²+λR(c), requiring a solver and conditioning analysis. Reconstructing the positions themselves is a nonlinear optimization using a position Jacobian, constraints, and applicable symmetries; matching |ρ|² adds phase ambiguity. No inverse reconstruction routine was identified in the inspected CCOptimization path; the required optimization acceleration is forward density plus adjoint-derived force.
